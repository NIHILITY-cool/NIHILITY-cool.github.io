图像检测：Faster R-CNN

Faster R-CNN（Faster Region-based Convolutional Neural Network 是一种经典的两阶段（two-stage）目标检测框架，通过深度神经网络同时完成目标类别预测和边界框定位。

Stage 1: 区域提议：Region Proposal 寻找可能包含目标的位置

Stage 2: 物体检测：Object Detection 对候选区域进行分类和位置精修

Faster R-CNN 基于 Fast R-CNN 进行改进，最大的创新是引入区域提议网络 RPN（Region Proposal Network）。它使用深度神经网络替代传统的区域提议算法（如 Selective Search），使候选框生成过程从人工设计的算法转变为可学习的网络模块。RPN 的引入带来了两个很重要的优点：

  1. 实现候选区域生成的可学习化

    RPN 使用深度神经网络替代传统人工设计的区域提议算法，通过学习目标特征自动生成候选框，使区域提议过程能够针对检测任务进行优化。

  2. 提高区域提议效率 RPN 将传统的区域搜索问题转化为基于卷积网络的预测问题，直接在 Feature Map 上通过并行卷积操作生成候选框，能够充分利用 GPU 计算能力，相比依赖 CPU 串行搜索的传统算法具有更高的生成速度。

1. 模型架构

1.1 Fast R-CNN 架构基础

Fast R-CNN 主要数据链路： 输入图像经过 Backbone 提取一次特征，得到共享的 Feature Map；随后利用候选区域（Region Proposal）在 Feature Map 上提取对应区域特征，并通过 RoI Pooling 将不同尺寸的候选区域转换为固定大小的特征表示，最后送入 RoI Head，分别进行目标分类和边界框回归

Faster R-CNN保留了这些主要链路，只拓展了 RPN 分支用于学习区域提议。

1.2 RPN

RPN 的主要数据流：首先使用一个滑动窗口（本质上是一个 3×33\times33×3 卷积层）处理共享 Feature Map。每个 Feature Map 位置对应 kkk 个 Anchor，作为 RPN 后续预测的初始参考框。

经过 3×33\times33×3 卷积得到的每个位置的特征，会分别送入两个并行的预测头：

  • 分类头（Cls Head）：通过 1×11\times11×1 卷积预测每个 Anchor 的物体性分数（Objectness Score），即该 Anchor 属于前景还是背景。
  • 回归头（Reg Head）：通过 1×11\times11×1 卷积预测每个 Anchor 的边界框偏移量 (tx,ty,tw,th)(t_x,t_y,t_w,t_h)(tx​,ty​,tw​,th​)，用于将 Anchor 调整为更接近真实目标的 Proposal。

推理阶段： RPN 输出的框在经过偏移变换和一系列筛选处理后输入到 ROI 模块，统一尺度后预测具体物品，并对预测框进行进一步的精准调整。

训练阶段： RPN 会随机采样 256 个 Anchor（其中 128 个正样本、128 个负样本）来计算 Loss 并优化网络。

锚框（Anchor）

得到共享 Feature Map 后，Feature Map（W×H×CW\times H\times CW×H×C）中的每一个空间位置都对应原图中的一个位置，并具有相应的感受野。

在每个位置上，会预设 kkk 个不同尺度和比例的 Anchor，作为后续边界框预测的初始参考框。

如论文中选择：

  • 3 种尺度：128、256、512
  • 3 种长宽比：1:11:11:1、1:21:21:2、2:12:12:1

因此每个 Feature Map 位置对应：

k=3×3=9k=3\times3=9k=3×3=9 个 Anchor。

注意： Anchor 是定义在原图坐标系中的参考框，而 Feature Map 上的空间位置用于确定 Anchor 的中心位置，并提供预测所需的特征。

RPN Head

在每个 Feature Map 位置，3×33\times33×3 卷积首先得到一个局部特征向量，然后由两个并行的 1×11\times11×1 卷积预测头进行预测。

1. Classification Head

对于每个 Anchor 判断其属于：

Foreground / Background\text{Foreground / Background}Foreground / Background

因此，每个位置需要对 kkk 个 Anchor 分别预测物体性分数。

原论文采用二分类形式，因此输出通道数为：2k2k2k

2. Regression Head

对每个 Anchor 预测四个边界框偏移量：

(tx,ty,tw,th)(t_x,t_y,t_w,t_h)(tx​,ty​,tw​,th​)

因此输出通道数为：4k4k4k

设 Anchor 为：

  • xa,yax_a,y_axa​,ya​：Anchor 的中心坐标
  • wa,haw_a,h_awa​,ha​：Anchor 的宽和高

训练

RPN 的训练需要划分正负样本，首先对每一个 Anchor，让它和与它 IoU 值最大的 GT框（Ground Truth）匹配：

若 IoU > 0.7，则为正样本，同时每一个 GT 框 IoU最大的 Anchor 也标记为正样本；

若 IoU < 0.3，则为负样本；

其余 Anchor 不参与 loss

训练时我们会分别采样最多 128 个正样本，其余补负样本进行 loss 计算和网络优化。

输出

RPN 的预测结果还需要经过一系列后处理，才能得到最终的 Region Proposals：

  1. 边界框解码：将回归头预测的偏移量 (tx,ty,tw,th)(t_x,t_y,t_w,t_h)(tx​,ty​,tw​,th​) 作用于对应的 Anchor，得到预测框；
  2. 边界框筛选：将超出图像边界的部分进行裁剪，并去除尺寸过小的预测框；
  3. 按物体性分数排序：根据 Objectness Score 对预测框排序，并保留 Top-NNN 个候选框；
  4. 非极大值抑制（NMS）：去除高度重叠的重复候选框；
  5. 再次保留 Top-NNN：得到最终送入 RoI Head 的 Region Proposals。
