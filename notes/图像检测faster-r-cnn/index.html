图像检测：Faster R-CNN

从 Region Proposal Network（RPN）到 ROI Head，理解 Faster R-CNN 的核心创新、完整链路、经典思想与后续发展。

2026年8月24日计算机视觉

图像检测：Faster R-CNN

Faster R-CNN（Faster Region-based Convolutional Neural Network 是一种经典的两阶段（two-stage）目标检测框架，通过深度神经网络同时完成目标类别预测和边界框定位。

Stage 1:

  • 区域提议：Region Proposal
  • 寻找可能包含目标的位置

Stage 2:

  • 物体检测：Object Detection
  • 对候选区域进行分类和位置精修

Faster R-CNN 基于 Fast R-CNN 进行改进，最大的创新是引入区域提议网络 RPN（Region Proposal Network）。它使用深度神经网络替代传统的区域提议算法（如 Selective Search），使候选框生成过程从人工设计的算法转变为可学习的网络模块。RPN 的引入带来了两个很重要的优点：

  1. 实现候选区域生成的可学习化

    RPN 使用深度神经网络替代传统人工设计的区域提议算法，通过学习目标特征自动生成候选框，使区域提议过程能够针对检测任务进行优化。

  2. 提高区域提议效率 RPN 将传统的区域搜索问题转化为基于卷积网络的预测问题，直接在 Feature Map 上通过并行卷积操作生成候选框，能够充分利用 GPU 计算能力，相比依赖 CPU 串行搜索的传统算法具有更高的生成速度。

1. 模型架构

1.1 Fast R-CNN 架构基础

Fast R-CNN 主要数据链路： 输入图像经过 Backbone 提取一次特征，得到共享的 Feature Map；随后利用候选区域（Region Proposal）在 Feature Map 上提取对应区域特征，并通过 RoI Pooling 将不同尺寸的候选区域转换为固定大小的特征表示，最后送入 RoI Head，分别进行目标分类和边界框回归。

Faster R-CNN保留了这些主要链路，只拓展了 RPN 分支用于学习区域提议。

1.2 RPN

RPN 的主要数据流：首先使用一个滑动窗口（本质上是一个 3×33\times33×3 卷积层）处理共享 Feature Map。每个 Feature Map 位置对应 kkk 个 Anchor，作为 RPN 后续预测的初始参考框。

经过 3×33\times33×3 卷积得到的每个位置的特征，会分别送入两个并行的预测头：

  • 分类头（Cls Head）：通过 1×11\times11×1 卷积预测每个 Anchor 的物体性分数（Objectness Score），即该 Anchor 属于前景还是背景。
  • 回归头（Reg Head）：通过 1×11\times11×1 卷积预测每个 Anchor 的边界框偏移量 (tx,ty,tw,th)(t_x,t_y,t_w,t_h)(tx​,ty​,tw​,th​)，用于将 Anchor 调整为更接近真实目标的 Proposal。

推理阶段： RPN 输出的框在经过偏移变换和一系列筛选处理后输入到 ROI 模块，统一尺度后预测具体物品，并对预测框进行进一步的精准调整。

训练阶段： RPN 会随机采样 256 个 Anchor（其中 128 个正样本、128 个负样本）来计算 Loss 并优化网络。

锚框（Anchor）

得到共享 Feature Map 后，Feature Map（W×H×CW\times H\times CW×H×C）中的每一个空间位置都对应原图中的一个位置，并具有相应的感受野。

在每个位置上，会预设 kkk 个不同尺度和比例的 Anchor，作为后续边界框预测的初始参考框。

如论文中选择：

  • 3 种尺度：128、256、512
  • 3 种长宽比：1:11:11:1、1:21:21:2、2:12:12:1

因此每个 Feature Map 位置对应：

k=3×3=9k=3\times3=9k=3×3=9 个 Anchor。

注意： Anchor 是定义在原图坐标系中的参考框，而 Feature Map 上的空间位置用于确定 Anchor 的中心位置，并提供预测所需的特征。

RPN Head

在每个 Feature Map 位置，3×33\times33×3 卷积首先得到一个局部特征向量，然后由两个并行的 1×11\times11×1 卷积预测头进行预测。

1. Classification Head

对于每个 Anchor 判断其属于：

Foreground / Background\text{Foreground / Background}Foreground / Background

因此，每个位置需要对 kkk 个 Anchor 分别预测物体性分数。

原论文采用二分类形式，因此输出通道数为：2k2k2k

2. Regression Head

对每个 Anchor 预测四个边界框偏移量：

(tx,ty,tw,th)(t_x,t_y,t_w,t_h)(tx​,ty​,tw​,th​)

因此输出通道数为：4k4k4k

设 Anchor 为：

其中：

  • xa,yax_a,y_axa​,ya​：Anchor 的中心坐标
  • wa,haw_a,h_awa​,ha​：Anchor 的宽和高

那么训练时的回归目标为：

训练

1. 正负样本

RPN 的训练需要划分正负样本，首先对每一个 Anchor，让它和与它 IoU 值最大的 GT框（Ground Truth）匹配：

若 IoU > 0.7，则为正样本，同时每一个 GT 框 IoU最大的 Anchor 也标记为正样本；

若 IoU < 0.3，则为负样本；

其余 Anchor 不参与 loss

训练时我们会分别采样最多 128 个正样本，其余补负样本进行 loss 计算和网络优化。

IoU(A,B)=∣A∩B∣∣A∪B∣IoU(A,B) = \frac{|A\cap{B}|}{|A\cup{B}|}IoU(A,B)=∣A∪B∣∣A∩B∣​

输出

RPN 的预测结果还需要经过一系列后处理，才能得到最终的 Region Proposals：

  1. 边界框解码：将回归头预测的偏移量 (tx,ty,tw,th)(t_x,t_y,t_w,t_h)(tx​,ty​,tw​,th​) 作用于对应的 Anchor，得到预测框；
  2. 边界框筛选：将超出图像边界的部分进行裁剪，并去除尺寸过小的预测框；
  3. 按物体性分数排序：根据 Objectness Score 对预测框排序，并保留 Top-NNN 个候选框；
  4. 非极大值抑制（NMS）：去除高度重叠的重复候选框；
  5. 再次保留 Top-NNN：得到最终送入 RoI Head 的 Region Proposals。

NMS（Non-Maximum Suppression，非极大值抑制）：按照置信度从高到低依次保留预测框，并删除与已保留框 IoU 超过阈值的低分重复框，从而减少同一目标对应的重复检测结果。

1.3 RoI

RPN 输出的 Region Proposals 只表示可能存在目标的候选区域，并没有给出具体类别，同时边界框位置也比较粗糙。因此需要将这些 Proposal 送入 RoI 模块，进一步完成目标分类和边界框精修。

RoI 的主要数据流：首先将 RPN 输出的 Proposal 从原图坐标映射到共享 Feature Map 上，得到对应的 RoI；随后通过 RoI Pooling 将不同尺寸的 RoI 转换为固定尺寸的特征，最后送入 RoI Head 进行具体类别预测和边界框回归。

RoI Head 同样包含两个并行的预测任务：

  • 分类头（Classification Head）：预测每个 RoI 所属于的具体目标类别，包括 Background 类。
  • 回归头（Bounding Box Regression Head）：预测边界框偏移量，对 RPN 生成的 Proposal 进行进一步精细调整。

推理阶段： RPN 输出的 Proposal 经过 RoI Pooling 和 RoI Head 后，得到具体类别概率以及精修后的边界框，再经过置信度筛选和 NMS 得到最终检测结果。

训练阶段： 将 Proposal 与 GT 框进行 IoU 匹配并划分正负样本。正样本同时参与分类和边界框回归 Loss，负样本只参与 Background 分类 Loss。

RoI Pooling

RPN 输出的 Proposal 位于原图坐标系中，而 RoI Head 使用的是 Backbone 输出的共享 Feature Map，因此首先需要将 Proposal 的坐标映射到 Feature Map 上，得到对应的 RoI（Region of Interest，感兴趣区域）。

由于不同 Proposal 对应的 RoI 尺寸不同，而后续全连接层需要固定大小的输入，因此 Faster R-CNN 使用 RoI Pooling 将不同尺寸的 RoI 特征统一为固定尺寸。

具体来说，将任意尺寸的 RoI：

Hroi×Wroi×CH_{\mathrm{roi}}\times W_{\mathrm{roi}}\times CHroi​×Wroi​×C

划分成固定数量的网格，并在每个网格内进行 Max Pooling，最终得到：

Hout×Wout×CH_{\mathrm{out}}\times W_{\mathrm{out}}\times CHout​×Wout​×C

的固定尺寸特征。

RoI Head

经过 RoI Pooling 后，每个 RoI 都被转换为固定尺寸的特征，随后送入 RoI Head。

与 RPN Head 类似，RoI Head 同样包含两个并行的预测任务。

1. Classification Head

RPN 的分类只判断一个 Anchor 属于 Foreground / Background，而 RoI Head 需要进一步判断 Proposal 对应的具体目标类别。

RoI Feature→具体目标类别\text{RoI Feature} \rightarrow \text{具体目标类别}RoI Feature→具体目标类别

假设共有 KKK 个目标类别，则输出类别概率：

p=(p0,p1,…,pK)p=(p_0,p_1,\ldots,p_K)p=(p0​,p1​,…,pK​)

其中 p0p_0p0​ 通常表示 Background 类。

2. Bounding Box Regression Head

RoI Head 还会再次对 Proposal 的位置进行边界框回归，预测：

(tx,ty,tw,th)(t_x,t_y,t_w,t_h)(tx​,ty​,tw​,th​)

并将其作用于当前 Proposal：

Proposal→(tx,ty,tw,th)→Refined Box\text{Proposal} \rightarrow (t_x,t_y,t_w,t_h) \rightarrow \text{Refined Box}Proposal→(tx​,ty​,tw​,th​)→Refined Box

这一过程与 RPN 中的边界框回归形式基本相同：

  • RPN 回归： Anchor →\rightarrow→ Proposal，完成候选区域的初步定位；
  • RoI Head 回归： Proposal →\rightarrow→ Refined Box，对候选框位置进行进一步精修。

因此 Faster R-CNN 实际包含两次边界框回归。

训练

1. 正负样本

RoI Head 的训练同样需要划分正负样本。

首先对于每一个 Proposal，计算其与所有 GT 框的 IoU，并选择 IoU 最大的 GT 框作为匹配目标。

随后根据匹配结果划分正负样本：

  • 与 GT 匹配程度较高的 Proposal 标记为正样本；
  • 与 GT 匹配程度较低的 Proposal 标记为背景样本。

对于正样本：

  • 分类头以其匹配 GT 的真实类别作为分类监督；
  • 回归头以匹配的 GT Box 作为回归目标，学习 Proposal 到 GT Box 的位置偏移。

对于负样本：

  • 只参与 Background 分类 Loss；
  • 不参与边界框回归 Loss。
2. 损失函数

与 RPN 部分相似，对于一个 RoI，其损失函数为：

L(p,u,tu,v)=Lcls(p,u)+λ[u≥1]Lloc(tu,v)L(p,u,t^u,v) = L_{\mathrm{cls}}(p,u) + \lambda [u\geq 1]L_{\mathrm{loc}}(t^u,v)L(p,u,tu,v)=Lcls​(p,u)+λ[u≥1]Lloc​(tu,v)

其中：

  • p=(p0,p1,…,pK)p=(p_0,p_1,\ldots,p_K)p=(p0​,p1​,…,pK​)：RoI Head 预测的各类别概率；
  • uuu：该 RoI 对应的真实类别，其中 u=0u=0u=0 表示 Background；
  • tut^utu：类别 uuu 对应的边界框回归预测；
  • vvv：Proposal 到其匹配 GT Box 的真实边界框回归目标；
  • [u≥1][u\geq1][u≥1]：指示函数，当 RoI 为前景样本时取 111，背景样本时取 000；
  • λ\lambdaλ：用于平衡分类损失和边界框回归损失，原论文中取 λ=1\lambda=1λ=1。

分类损失采用多分类交叉熵：

Lcls(p,u)=−log⁡puL_{\mathrm{cls}}(p,u) = -\log p_uLcls​(p,u)=−logpu​

其中 pup_upu​ 表示模型预测该 RoI 属于真实类别 uuu 的概率。

边界框回归损失采用 Smooth L1 Loss：

Lloc(tu,v)=∑i∈{x,y,w,h}smooth⁡L1(tiu−vi)L_{\mathrm{loc}}(t^u,v) = \sum_{i\in\{x,y,w,h\}} \operatorname{smooth}_{L_1} \left(t_i^u-v_i\right)Lloc​(tu,v)=i∈{x,y,w,h}∑​smoothL1​​(tiu​−vi​)

通RPN，由于边界框回归项前存在指示函数：

  • 正样本 RoI：同时参与分类 Loss 和边界框回归 Loss；
  • 背景 RoI：只参与分类 Loss，不参与边界框回归 Loss。

另外，原始 Faster R-CNN 中 RoI Head 的边界框回归是类别相关的（Class-specific）。

假设共有 KKK 个前景类别，则回归头会输出 4K4K4K 个回归量，每个类别分别对应一组：

(tx,ty,tw,th)(t_x,t_y,t_w,t_h)(tx​,ty​,tw​,th​)

对于真实类别为 uuu 的正样本 RoI，只使用类别 uuu 对应的那一组 tut^utu 与回归目标 vvv 计算边界框回归 Loss。

输出

经过 RoI Head 后，每个 Proposal 会得到两类预测结果：

  1. 类别预测：输出具体目标类别及对应的置信度；
  2. 边界框回归：根据预测偏移量进一步调整 Proposal 的位置。

随后还需要经过后处理：

  1. 根据分类置信度过滤低分预测；
  2. 根据边界框回归结果对 Proposal 进行解码，得到精修后的预测框；
  3. 对各类别预测框进行 NMS，去除重复检测结果；
  4. 得到最终目标检测结果：
(Class, Score, Bounding Box)(\text{Class},\ \text{Score},\ \text{Bounding Box})(Class, Score, Bounding Box)返回笔记
